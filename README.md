# MafiFlow Android 1.0.9 — Beta 21

## Corrección de esta versión
- Las flechas de “Reportar un error” y “Sugerir una función” ahora giran hacia abajo al abrir su formulario.
- Al volver a tocar la misma opción, el formulario se cierra y la flecha regresa a la derecha.
- Cada flecha refleja el estado de su propia sección.
- Se conservan CUP, la calculadora adaptable, el icono y las demás funciones de Beta 20.

## Compilar para Android
Sube el contenido de este ZIP al repositorio de MafiFlow Android y ejecuta GitHub Actions para generar el APK y el AAB.

Esta versión contiene el código fuente Flutter, no un APK ya compilado. Ejecuta el workflow y prueba el formulario en el teléfono antes de publicar en Google Play.
